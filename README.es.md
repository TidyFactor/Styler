## ⚡ Inicio Rápido (Quickstart)

```bash
# Instalación e invocación vía NPX
npx @alwkala/tidyfactor-styler
```

O invócalo directamente en tu asistente de codificación con IA (*Google Antigravity, Claude Code, Cursor, Codex*):
```text
/tidyfactor-styler component
```

---

## 🎯 ¿Qué es TidyFactor Styler?

`tidyfactor-styler` es un motor de diseño e ingeniería de interfaz que opera **directamente dentro de tu código existente** (React/Next.js, PHP Plates/Blade, WordPress, HTML/CSS) sin inventar capas de estilos innecesarias ni dependencias extrañas.

## 📋 Matriz de Comandos Principales

| Comando | Objetivo y Resultado | Flujo de Trabajo |
|---|---|---|
| `/brief` | Descubrimiento y establecimiento de la línea base de diseño | `workflows/brief.md` |
| `/component` | Creación o rediseño quirúrgico de componentes UI | `workflows/component-create.md` |
| `/section` | Creación o rediseño de secciones completas | `workflows/section-create.md` |
| `/page` | Construcción de páginas de producción completas | `workflows/page-create.md` |
| `/redesign` | Rediseño de páginas existentes sin romper la arquitectura | `workflows/page-redesign.md` |
| `/rtl` | Auditoría y corrección quirúrgica de propiedades lógicas RTL | `workflows/rtl-audit-fix.md` |
| `/typography` | Emparejamiento tipográfico y escalas de fuentes (incl. Árabe) | `memory/typography-arabic.md` |
| `/palette` | Extracción de tokens de marca y contraste WCAG AA | `memory/brand-tokens.md` |
| `/motion` | Principios y micro-interacciones de movimiento premium | `memory/motion-principles.md` |
