## ⚡ Início Rápido (Quickstart)

```bash
# Instalação e execução via NPX
npx @alwkala/tidyfactor-styler
```

Ou execute diretamente dentro do seu assistente de IA (*Google Antigravity, Claude Code, Cursor, Codex*):
```text
/tidyfactor-styler component
```

---

## 🎯 O que é o TidyFactor Styler?

O `tidyfactor-styler` é um motor de design e engenharia de interface que opera **diretamente dentro da base de código existente** (React/Next.js, PHP, WordPress, HTML/CSS) respeitando rigorosamente suas convenções nativas.

## 📋 Matriz de Comandos Principais

| Comando | Objetivo e Resultado | Fluxo de Trabalho |
|---|---|---|
| `/brief` | Alinhamento e definição da linha base de design | `workflows/brief.md` |
| `/component` | Criação ou redesign cirúrgico de componentes UI | `workflows/component-create.md` |
| `/section` | Criação ou redesign de seções estruturadas | `workflows/section-create.md` |
| `/page` | Construção de páginas prontas para produção | `workflows/page-create.md` |
| `/redesign` | Redesign de páginas existentes preservando a arquitetura | `workflows/page-redesign.md` |
| `/rtl` | Auditoria e refatoração para propriedades lógicas RTL | `workflows/rtl-audit-fix.md` |
| `/typography` | Harmonização de fontes e escalas tipográficas | `memory/typography-arabic.md` |
| `/palette` | Extração de tokens de cores e contraste WCAG AA | `memory/brand-tokens.md` |
| `/motion` | Princípios de animação e micro-interações | `memory/motion-principles.md` |
