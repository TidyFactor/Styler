# 2. Navigation & Footer Catalogs

Reference catalog for Navigation (N1–N9) and Footer (Ft1–Ft8) components across production codebases.

## Navigation Archetypes (N1–N9)

| Code | Archetype Name | Visual Structure & Layout | Best For |
|---|---|---|---|
| **N1** | **Floating Pill** | Glassmorphic floating pill (`max-w-fit mx-auto rounded-full px-6 py-3 border backdrop-blur-md`) | Modern SaaS, mobile-first web apps, startup landing pages |
| **N2** | **Newspaper Masthead** | Centered brand title with top/bottom divider rules and category navigation links below | Editorial platforms, blogs, news portals |
| **N3** | **Brutal Slab** | Stark 3px/4px hard border, monochrome uppercase labels, sharp corner edges | Neo-Brutalism, creative agencies, street fashion |
| **N4** | **Terminal / CLI** | Monospace typography with prompt caret `>` markers on dark background | Developer tools, API documentation, technical platforms |
| **N5** | **Edge-Aligned Minimal** | Wordmark aligned hard left (`justify-between`), navigation links hard right | Minimalist, luxury brands, portfolio sites |
| **N6** | **Split Brand** | Centered brand emblem with links balanced on left and right sides | High-end luxury, hospitality, heritage brands |
| **N7** | **Double-Decker Utility** | Top notification/language/contact bar paired with main brand header below | E-commerce, corporate portals, multilingual sites |
| **N8** | **Vertical Rail** | Fixed left/right navigation rail with icon tooltips (`w-16 h-screen flex-col`) | Web app dashboards, SaaS control panels |
| **N9** | **Fullscreen Overlay** | Minimal header trigger button opening full-viewport navigation overlay | Creative portfolios, immersive brand experiences |

## Footer Archetypes (Ft1–Ft8)

| Code | Archetype Name | Visual Structure & Layout | Best For |
|---|---|---|---|
| **Ft1** | **Mast-Headed** | Giant brand wordmark overlaying top of footer with multi-column link grid below | Flagship brand sites, agencies |
| **Ft2** | **Minimal Inline** | Clean single-line layout (`flex justify-between items-center`) with wordmark, links & copyright | Single-page apps, simple product sites |
| **Ft3** | **Colophon / Credits** | Displays build metadata, typography credits, server location, and license details | Technical sites, developer projects, open-source |
| **Ft4** | **Big Statement** | Prominent mission statement or quote block preceding link navigation grid | Non-profits, brand manifestos, agencies |
| **Ft5** | **Letter Close** | Personal signed letter from founder/creator with CTA button before footer links | Creator products, newsletters, personal brands |
| **Ft6** | **Newsletter-First** | Large email signup form occupying primary focal space above footer links | Content platforms, blogs, DTC brands |
| **Ft7** | **Marquee Scroll** | Continuous horizontal text ticker banner above secondary links | Fashion, creative portfolios, brutalist sites |
| **Ft8** | **Sitemap Grid** | Comprehensive multi-column link directory with locale, language, and theme switchers | Enterprise SaaS, complex web platforms |
