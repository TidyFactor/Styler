## ⚡ راه‌اندازی سریع (Quickstart)

```bash
# نصب و اجرای مستقیم از طریق NPX
npx @alwkala/tidyfactor-styler
```

یا فراخوانی مستقیم در دستیار برنامه‌نویسی (*Google Antigravity, Claude Code, Cursor, Codex*):
```text
/tidyfactor-styler component
```

---

## 🎯 تایدی‌فاکتور استایلر چیست؟

مهارت `tidyfactor-styler` یک موتور مهندسی رابط کاربری است که **مستقیماً درون کدهای واقعی پروژه شما** (React/Next.js, PHP, WordPress, HTML/CSS) عمل می‌کند بدون اینکه ساختار فایل‌ها یا معماری اصلی پروژه را به هم بریزد.

## 📋 ماتریس دستورات اصلی

| دستور | هدف و نتیجه | جریان کاری (Workflow) |
|---|---|---|
| `/brief` | ثبت بریف طراحی و هماهنگی پیش‌نیازهای بصری | `workflows/brief.md` |
| `/component` | ساخت یا بازطراحی جراحی‌گونه کامپوننت‌های رابط کاربری | `workflows/component-create.md` |
| `/section` | ساخت یا بازطراحی سکشن‌های ساختاریافته | `workflows/section-create.md` |
| `/page` | تولید صفحات آماده استفاده در محیط پروداکشن | `workflows/page-create.md` |
| `/redesign` | بازطراحی صفحات موجود با حفظ معماری کد | `workflows/page-redesign.md` |
| `/rtl` | ممیزی و تبدیل دقیق استایل‌ها به Logical Properties راست‌چین | `workflows/rtl-audit-fix.md` |
| `/typography` | انتخاب و ست‌کردن تایپوگرافی فارسی/عربی و فونت‌های استاندارد | `memory/typography-arabic.md` |
| `/palette` | استخراج پالت رنگی استاندارد و کنتراست WCAG AA | `memory/brand-tokens.md` |
| `/motion` | اصول موشن دیزاین و میکرو-انیمیشن‌های تعاملی | `memory/motion-principles.md` |
