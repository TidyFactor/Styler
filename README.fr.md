---

## 🎯 Qu'est-ce que TidyFactor Styler ?

`tidyfactor-styler` est un moteur d'ingénierie UI qui intervient **directement au sein de votre base de code existante** (React/Next.js, PHP, WordPress, HTML/CSS) tout en respectant scrupuleusement vos conventions architecturales.

## 📋 Matrice des Commandes Principales

| Commande | Objectif & Résultat | Référence de Workflow |
|---|---|---|
| `/brief` | Alignement du brief de design et de la ligne directrice | `workflows/brief.md` |
| `/component` | Création ou refonte chirurgicale de composants UI | `workflows/component-create.md` |
| `/section` | Conception ou redesign de sections structurées | `workflows/section-create.md` |
| `/page` | Développement de pages complètes prêtes pour la production | `workflows/page-create.md` |
| `/redesign` | Refonte de pages existantes sans rupture d'architecture | `workflows/page-redesign.md` |
| `/rtl` | Audit et conversion vers les propriétés logiques CSS (RTL) | `workflows/rtl-audit-fix.md` |
| `/typography` | Appariement typographique et hiérarchie des polices | `memory/typography-arabic.md` |
| `/palette` | Extraction des tokens de marque et validation WCAG AA | `memory/brand-tokens.md` |
| `/motion` | Principes de mouvement et micro-interactions | `memory/motion-principles.md` |
