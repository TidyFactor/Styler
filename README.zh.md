```bash
npx @alwkala/tidyfactor-styler
```

或在 AI 编码助手 (*Google Antigravity, Claude Code, Cursor, Codex*) 中调用：
```text
/tidyfactor-styler component
```

---

## 🎯 什么是 TidyFactor Styler？

`tidyfactor-styler` 是一个直接在您**现有生产代码库**（React/Next.js、PHP、WordPress、HTML/CSS）中运行的 UI 设计与工程引擎，严格遵循既有项目的规范，绝不引入冗余的样式层或无关依赖。

---

## 📋 核心命令矩阵

| 命令 | 目标与产出 | 执行工作流 |
|---|---|---|
| `/brief` | 建立设计基线与风格对齐 | `workflows/brief.md` |
| `/component` | 生产级组件的新建或微创重构 | `workflows/component-create.md` |
| `/section` | 结构化区块的新建或重构 | `workflows/section-create.md` |
| `/page` | 生产环境完整页面的构建 | `workflows/page-create.md` |
| `/redesign` | 在不破坏现有架构的前提下重构页面 | `workflows/page-redesign.md` |
| `/rtl` | RTL 逻辑属性与阿拉伯/波斯语排版审计修复 | `workflows/rtl-audit-fix.md` |
| `/typography` | 字体配对与层次规范 | `memory/typography-arabic.md` |
| `/palette` | 提取品牌色彩 Token 与 WCAG AA 对比度校验 | `memory/brand-tokens.md` |
| `/motion` | 高端交互动效与过渡原则 | `memory/motion-principles.md` |
