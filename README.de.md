## ⚡ Schnellstart (Quickstart)

```bash
# Installation & Direktaufruf via NPX
npx @alwkala/tidyfactor-styler
```

Oder direkt in Ihrem KI-Assistenten aufrufen (*Google Antigravity, Claude Code, Cursor, Codex*):
```text
/tidyfactor-styler component
```

---

## 🎯 Was ist TidyFactor Styler?

`tidyfactor-styler` ist eine UI-Engineering-Engine, die **direkt innerhalb Ihrer bestehenden Codebasis** (React/Next.js, PHP, WordPress, HTML/CSS) arbeitet, ohne fremde Abhängigkeiten oder redundante Style-Dateien einzuführen.

## 📋 Befehls- & Workflow-Matrix

| Befehl | Ziel & Ergebnis | Workflow-Referenz |
|---|---|---|
| `/brief` | Definition der Design-Baseline und des Anforderungs-Briefings | `workflows/brief.md` |
| `/component` | Erstellung oder gezieltes Redesign von UI-Komponenten | `workflows/component-create.md` |
| `/section` | Aufbau oder Redesign strukturierter Page-Sections | `workflows/section-create.md` |
| `/page` | Entwicklung vollständiger produktionsreifer Seiten | `workflows/page-create.md` |
| `/redesign` | Redesign bestehender Seiten unter Beibehaltung der Architektur | `workflows/page-redesign.md` |
| `/rtl` | Audit und Refactoring auf logische CSS-Properties (RTL) | `workflows/rtl-audit-fix.md` |
| `/typography` | Schriftpaarung und typografische Hierarchie | `memory/typography-arabic.md` |
| `/palette` | Extraktion von Design-Tokens und WCAG AA Kontrastprüfung | `memory/brand-tokens.md` |
| `/motion` | Richtlinien für Interaktionsdesign und Animationen | `memory/motion-principles.md` |
